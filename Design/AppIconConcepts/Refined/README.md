# Original-lettering icon concepts

This round addresses the shapes and typography of the earlier concepts. It uses contours traced with Apple's Vision framework from `Shared/Resources/Rudolstadt.icon/Assets/icon.png`, the actual existing stacked festival lettering. There is no substitute typeface, newly drawn letterform, decorative square orbit, or programme illustration.

- `07-original-pur.icon`: complete original lettering on violet, restrained material highlights.
- `08-ru-signet.icon`: the original first two letters as a compact identity, with native glass highlights.
- `09-original-hell.icon`: complete original lettering in violet on a light background.

Every package contains one SVG vector layer with native glass enabled. Full-wordmark variants preserve all ten glyphs, including the l, and all four counters. The ru variant intentionally uses only the first two original glyphs. Background gradients, material lighting, translucency and shadows are generated by Icon Composer, not baked into the artwork. Each group uses combined lighting.

`Previews/originalschriftzug-vergleich.png` shows Apple's compiled macOS rendering at large and small sizes. The dark-background comparison shows the same standard appearance, not a separate Dark Mode rendition. These are native compiler exports, not iPhone screenshots.

Both macOS 12.2 and iOS 18 asset compilation were verified. The application was not built or launched, and its active icon was not replaced.

To reproduce, run `generate-refined-icons.swift` with the existing PNG path and this output directory. Contour detection requires local access to Apple's image-processing services. Compile each resulting package with `xcrun actool`, then run `render-native-previews.swift` with the compiled output directory, a preview directory, and `--refined`.
